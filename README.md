# 🇷🇺 CollectionLeague

Discord-бот с коллекционной системой карточек, игровой экономикой, дропами, бустерами и крафтом.

Проект написан на **Python** с использованием **disnake** и **SQLite**.

> **Авторская заметка:** этот проект был разработан **до начала моего использования AI-инструментов для программирования**. Код этого проекта написан мной без генерации кода ИИ (**0% AI-generated code**).

## ✨ Возможности

- Коллекционные карточки с несколькими редкостями.
- Система случайных дропов.
- Выбор одной из двух карточек после дропа.
- Бустеры с различными шансами выпадения редкостей.
- Продажа карточек.
- Крафт / улучшение карточек.
- Игровая валюта.
- Профили и инвентари пользователей.
- Статистика коллекции.
- Prefix-команды и Discord Slash Commands.
- SQLite-база данных.
- Фоновые изображения для результатов дропа.
- Административные команды для тестирования и управления балансом.

## 🃏 Карточки

Карточки проекта рассчитаны примерно на соотношение сторон **2:3**, то есть ориентировочно **4×6**.

Полная коллекция карточек намеренно **не входит в публичный репозиторий**. Локальная папка `cards/` используется ботом, но исключена через `.gitignore`.



## 🛠 Требования

- **Python 3.10+**
- Discord Bot Application
- Discord Bot Token
- Зависимости из `requirements.txt`

Проект использует:

- `disnake` — взаимодействие с Discord.
- `python-dotenv` — загрузка токена из `.env`.
- `sqlite3` — локальная база данных SQLite.

## 🚀 Установка

### 1. Клонирование репозитория

```bash
git clone https://github.com/DimaTiron/CollectionLeague.git
cd CollectionLeague
```

### 2. Создание виртуального окружения

Windows:

```bash
python -m venv .venv
.venv\Scripts\activate
```

Linux / macOS:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
python -m pip install -r requirements.txt
```

### 4. Настройка Discord Bot Token

Создайте в корне проекта файл:

```text
.env
```

и добавьте:

```env
DISCORD_TOKEN=your_discord_bot_token
```

Файл `.env` **не должен публиковаться**. Он уже добавлен в `.gitignore`.

В репозитории также находится:

```text
.env.example
```

Его можно скопировать в `.env` и заменить значение токена.

### 5. Запуск

```bash
python main.py
```

## 📋 Команды

Prefix проекта:

```text

```

### Основные команды

| Команда | Алиасы | Описание |
|---|---|---|
| `!!дроп` | `!!drop` | Получить случайный дроп. |
| `!!работать` | `!!work` | Заработать случайное количество монет. |
| `!!бустера` | `!!shop`, `!!boosters`, `!!packs`, `!!cases`, `!!магазин` | Открыть магазин бустеров. |
| `!!открыть <booster>` | `!!open` | Открыть имеющийся бустер. |
| `!!шансы` | `!!chances`, `!!dropinfo` | Посмотреть шансы выпадения. |
| `!!инвентарь` | `!!карты`, `!!inventory`, `!!cards`, `!!inv`, `!!коллекция` | Посмотреть карточки и бустеры. |
| `!!профиль` | `!!меню`, `!!баланс`, `!!balance` | Профиль, баланс и статистика коллекции. |
| `!!экономика` | `!!цены`, `!!economy`, `!!costs` | Цены карточек и стоимость крафта. |
| `!!посмотреть <card>` | `!!see` | Посмотреть свою карточку. |
| `!!продать <card> [amount]` | `!!sell` | Продать карточку или несколько копий. |
| `!!улучшить <card>` | `!!upgrade`, `!!upg`, `!!upgr`, `!!up` | Улучшить карточку через крафт. |
| `!!помощь` | `!!help`, `!!info`, `!!инфо` | Показать список команд. |
| `!!cat` | `!!кот`, `!!cats`, `!!kitty` | Отправить случайное изображение кота. | -- по приколу
| `!!dog` | `!!puppy`, `!!doggy`, `!!пёс`, `!!собака` | Отправить случайное изображение собаки. |  -- по приколу

## 🎮 Как работает игровая система

### Дропы

Дроп позволяет получить одну из карточек или игровую валюту. Вероятности выпадения настраиваются в:

```text
functions/variables.py
```

### Бустеры

Бустеры имеют разные стоимости и распределения вероятностей по редкостям.

### Крафт

Две копии одной карточки могут использоваться для получения карточки более высокой редкости с дополнительной стоимостью в монетах.

### Экономика

Игроки могут:

- получать монеты;
- покупать бустеры;
- получать карточки;
- продавать карточки;
- создавать более редкие карточки через крафт.

## 📁 Структура проекта

```text
CollectionLeague/
├── backgrounds/              # Фоновые изображения
├── cogs/                     # Discord-команды и события
├── functions/                # База данных и игровая логика
├── examples/                 # Публичные примеры карточек
├── screenshots/              # Публичные скриншоты работы бота
├── main.py                   # Точка входа
├── requirements.txt          # Зависимости
├── .env.example              # Пример конфигурации
├── .gitignore                # Исключения Git
└── README.md
```

Следующие файлы и папки остаются локальными и не публикуются:

```text
cards/
For cards creation/
*.db
.env
.idea/
__pycache__/
*.pyc
*.log
```

Это позволяет публиковать исходный код без личных данных пользователей, локальной базы и приватных файлов.

## 💾 База данных

Проект использует SQLite.

Файл базы данных **не включён в репозиторий**, поскольку он может содержать реальные данные пользователей Discord.

При запуске проекта база создаётся / обновляется локально.
